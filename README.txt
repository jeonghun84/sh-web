신흥쇼트기계 홈페이지 v2

업로드된 '신흥쇼트 사진.zip'의 실제 현장 사진과 기존 카탈로그를 반영한 버전입니다.

포함 내용
- 실제 현장 사진을 사용한 메인 비주얼
- 사업분야: 쇼트블라스트 설비 + 쇼트닝
- 제품: Hanger / Rotary Hanger / Apron / Air Blast Room / Dust Collector / Shot Separator
- Impeller Unit 대표 사양
- 기존 카탈로그 원본 확대 보기
- 현장 사진 갤러리
- 설비 상담 프로세스
- 반응형 모바일 디자인

확인이 필요한 항목
- 대표전화
- 이메일
- 사업장 주소
- 상담시간
- '쇼트닝'의 구체적인 서비스 범위/표현
- 실제 온라인 문의 전송 방식

사용법
index.html을 브라우저에서 열면 됩니다.
